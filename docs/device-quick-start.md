# Robo Device Quick-Start Card (Draft)

This card is a draft for the first hardware prototype. Firmware and final
button labels are still in progress; update it after the device build is
validated.

## In the box

- Robo device
- USB-C power cable and adapter
- Quick-start card

## Setup

1. Plug in the device. The LED pulses while it boots.
2. On your phone, open **Robo → Devices → Pair a device**.
3. Enter the pairing code shown on the device screen, or scan the QR code when
   the firmware supports it.
4. Choose your Wi-Fi network and enter its password. The phone sends the
   credentials to the device over Bluetooth.
5. Wait for the LED to turn solid. Robo says "Ready" when setup is complete.
6. Tap the microphone button and say "What can you do?" to test the connection.

## Controls

| Control | Action |
| --- | --- |
| Microphone button | Start or stop talking |
| Mute switch | Physically disconnects the microphones; the LED turns red |
| Volume buttons | Raise or lower playback volume |
| Reset button (hold 10 s) | Factory reset; removes Wi-Fi and pairing data |
| Power input | USB-C, 5 V |

## Status lights

| Light | Meaning |
| --- | --- |
| Pulsing blue | Booting or connecting |
| Solid blue | Ready |
| Spinning blue | Listening or thinking |
| Solid green | Timer or reminder active |
| Solid red | Muted, offline or error |

## Safety

- Keep the device away from water and heat.
- Use only the supplied power adapter.
- Unplug before cleaning. Do not open the case; there are no user-serviceable
  parts.
- The device is not a toy and is not intended for children under 18 in v1.

## Troubleshooting

- **LED stays red**: check the mute switch and the power cable.
- **Cannot find the device**: move it within 2 m of the phone, restart it, and
  try pairing again.
- **Wi-Fi setup fails**: use a 2.4 GHz network; captive portals are not
  supported.
- **No sound**: raise the volume, check the mute switch, and confirm the device
  shows solid blue.
- **Factory reset**: hold the reset button for 10 seconds, then repeat setup.
